# GSRTC Journey Demo

GSRTC Journey Demo is an independent, GSRTC-inspired passenger bus-booking prototype. It includes sample route search, passenger-count seat selection, group traveller details, a structured demo ticket PDF, SMS/WhatsApp sharing previews, and a simulated journey monitor.

> **Important:** This is an independent prototype. It is not affiliated with GSRTC, does not create real reservations, does not process payments, and does not provide a ticket valid for travel. Schedules, fares, seats, vehicle positions, and ETAs are illustrative until authorised operator data and production services are connected.

## Development

Install dependencies with `pnpm install`, then run `pnpm dev`. Type-check with `pnpm run check` and build with `pnpm run build`.

## Public repository

Source code: https://github.com/kalariya-ved/gsrtc-journey-demo
