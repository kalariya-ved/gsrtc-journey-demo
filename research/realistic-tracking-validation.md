# Realistic Journey Monitor Validation

The Journey Monitor now interpolates the simulated vehicle continuously along the managed road route between tracking snapshots instead of jumping between fixed points. The marker uses fractional path positions and rotates with the road direction. Snapshot updates are spaced at 6.2 seconds, with eased movement between positions. Snapshots also include explicit simulated corridor states: on corridor, minor deviation with a temporary detour notice, and recovered after rejoining the planned corridor. Desktop and mobile screenshots confirmed the moving-road label, fractional route completion, responsive controls, map fallback, ETA panel, stop timeline, and independent-simulation disclosure remain readable. Actual operator live tracking is still not claimed; an authorised vehicle-location feed is required for production use.
